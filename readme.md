# SoloWanderCircle.in

Responsive static website for SoloWanderCircle.

## Files
- index.html
- styles.css
- script.js

## Before launch
1. Replace the Instagram/other social links as needed.
2. Replace Unsplash image URLs with your own licensed trip/community photos for production.
3. Upload these files to your web host and point `solowandercircle.in` DNS to it.
