# SoloWanderCircle.in

Responsive static website for SoloWanderCircle.

## Files
- index.html
- styles.css
- script.js

## Before launch
1. Replace the placeholder WhatsApp number `919999999999` in `script.js`.
2. Replace the Instagram/other social links as needed.
3. Replace Unsplash image URLs with your own licensed trip/community photos for production.
4. Upload these files to your web host and point `solowandercircle.in` DNS to it.
