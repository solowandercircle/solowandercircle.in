## Before launch
1. Replace the placeholder photos in the `images/` directory with your actual images (including `meetup-1.jpg`, `meetup-2.jpg`, and `meetup-escape.jpg`).
2. Replace the placeholder WhatsApp number `919999999999` in `script.js`.
3. Replace the Instagram/other social links as needed.
4. Upload these files to your web host and point `solowandercircle.in` DNS to it.
